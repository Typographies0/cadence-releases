# Cadence releases

Downloads for [Cadence](https://github.com/Typographies0), a calendar, tasks and planning app.
This repo holds only the built apps; the code is private.

**Get the latest version:** [Releases](../../releases/latest)

## Mac (Apple Silicon, M1 and newer)

1. Download `Cadence-<version>-mac-arm64.zip`, unzip it and drag **Cadence** into **Applications**.
2. Open it. The app isn't signed by Apple, so macOS blocks it the first time: open
   **System Settings → Privacy & Security** and click **Open Anyway**.

Your data stays on your own Mac (`~/Library/Application Support/cadence/`).
